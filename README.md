# techbridge-doc

schoopilotシステムで運用する自社テナント向けの研修ドキュメント管理リポジトリです。

## フォルダ構成

各ポジションごとにフォルダを分け、研修単位でMarkdownファイルを管理します。

```
techbridge-doc/
├── スタッフ（初級）/   # 入社直後〜基本業務習得まで
├── スタッフ（中級）/   # 基本業務習得後〜コミュニケーション強化
├── サブリーダー/
├── リーダー/
└── マネージャー/
```

## ファイル命名規則

- `連番_研修タイトル.md`（例: `01_オンボーディングと基本ルール.md`）
- 連番により、推奨される実施順序を示しています

## ドキュメント構成

各研修ファイルは以下の構成で記載します。

```markdown
# 研修タイトル

## 研修内容

研修で学ぶ内容の詳細

## 修了の基準

修了と判断するための条件
```
